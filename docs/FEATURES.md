# ✨ Features

**English** · [简体中文](FEATURES.zh-CN.md) · [🏠 Home](../README.md)

PyDeck brings Python installation, environments and local builds into one Windows desktop workspace.

| Area | What you can do | Guide |
| --- | --- | --- |
| 🐍 Python versions | Browse current and historical packages; install, update, repair, select a default and prepare offline bundles | [Python management](MANAGEMENT.md) |
| 📦 Environments and packages | Create/import venvs, open terminals, manage pip packages and import/export supported requirements | [Python management](MANAGEMENT.md) |
| 🛠️ Build Python | Select official or local CPython sources, compiler/SDK and components; use Standard, Performance, Debug, Minimal or Custom presets | [Build Python](BUILD_PYTHON.md) |
| 🧹 Storage and usage | Review build caches and local runtimes before cleanup; inspect registered environment dependencies | [Python management](MANAGEMENT.md) |
| ⚙️ Configuration | Manage PIM preferences, PATH diagnostics, aliases, HTTPS sources, proxies and Shebang rules | [Python management](MANAGEMENT.md) |
| 🎨 Appearance | Choose Material 3 Expressive or Windows Fluent; configure dynamic colors, startup, window behavior and language | [Design systems](DESIGN_SYSTEMS.md), [Monet](MONET.md) |
| 📦 Installation | Use offline Setup or standalone current-user MSI; choose folder, shortcuts and initial style | [Install PyDeck](INSTALL.md) |

The interface supports English, Simplified Chinese, Traditional Chinese (Taiwan) and Japanese. Independent tasks have their own progress and cancellation; Activity provides session logs and severity filters.

PyDeck targets Windows 11 x64. Python installation changes require PIM 26.3 or later; local builds and venvs can use local runtimes without PIM. Package management is limited to registered venvs, and build compatibility depends on the selected CPython source and toolchain. Detailed operating limits are kept in the linked guides.
