# 🐍 PyDeck 0.7.1-fix

**English** · [简体中文](#简体中文) · **2026-10-03 · Asia/Taipei**

## ✨ Interface and colors

- 🎨 Independent **Windows Fluent** and **Material 3 Expressive** interfaces, with their own navigation, page layouts, typography and components. Fluent retains Windows materials; Material uses opaque tonal surfaces and rounded controls
- 🔁 Style changes take effect after restarting. Settings offers **Restart now** or **Later**; the restart button starts disabled for **1.8 seconds**, and active work prevents restarting. Theme and language changes remain immediate
- 🖼️ Material colors follow the local desktop wallpaper or your custom colors, using pinned AOSP seed selection and the official Material Color Utilities HCT engine
- 🎨 Choose **Balanced (TonalSpot)**, **Expressive**, or **Two colors**. The two-color mode is PyDeck's **`DualSource` extension**: the first source supplies primary actions and neutral surfaces; the second supplies secondary/tertiary accents. It uses the pinned MCU 2021 solver, **not a full port of Google's CMF variant or the 2026 color specification**
- Wallpaper mode uses two distinct color candidates when available, with a single-source fallback. Manual colors are saved together when applied; background wallpaper updates wait before changing an active editor's palette

## 🔧 Controls and installation

- Left-aligned search text, rounded Material search fields, and native input, clear and query behavior with debounced filtering
- Tonal dropdown selection with checkmarks; consistent corners for custom-color, build-storage and other expandable sections
- Material refresh and operation progress indicators follow the theme's primary and secondary-container colors
- Rounded Material scrollbar handles with theme-colored hover/drag states and no arrow buttons; version groups no longer have a redundant bottom rule
- 📦 An offline **Setup** entry point prepares missing shared runtimes before opening the MSI folder/shortcut wizard. Standalone MSI and MSIX remain available
- 🌏 English remains the default; Simplified Chinese, Traditional Chinese (Taiwan), and Japanese remain available

## 简体中文

### ✨ 界面与配色

- 🎨 **Windows Fluent** 与 **Material 3 Expressive** 分开实现导航、页面布局、字体和组件；Fluent 保留 Windows 材质，Material 使用不透明色调表面和圆角控件
- 🔁 切换风格后重启生效，设置提供“立即重启”与“稍后”；重启按钮默认先禁用 **1.8 秒**，有任务运行时仍不能重启，明暗主题和语言仍即时切换
- 🖼️ Material 支持桌面壁纸本地取色或自定义颜色，使用固定版本的 AOSP 种子筛选与官方 Material Color Utilities HCT 引擎
- 🎨 可选择“均衡（TonalSpot）”、Expressive 或“双色”。双色是 PyDeck 的 **`DualSource` 扩展**：第一色控制主操作和中性表面，第二色提供次级与第三色系；使用固定的 MCU 2021 求解规则，**不是 Google CMF 变体或 2026 配色规范的完整移植**
- 壁纸有合适候选时采用两色，否则回退到单一来源；手动颜色点击应用后一起保存，后台壁纸配色会等待合适时机再应用，避免打断正在编辑的页面

### 🔧 控件与安装

- 搜索文字左对齐，Material 搜索框采用圆角；保留原生输入、清除、查询行为和搜索防抖
- 下拉选项采用色调选中背景与勾选标记，自定义颜色、构建空间管理等折叠面板统一圆角
- Material 的刷新与操作进度指示统一使用主题的主色和次级容器色
- Material 滚动条采用无箭头圆角滑块，悬停和拖动使用主题色；版本分组去掉末尾多余横线
- 📦 新增离线 **Setup** 入口，先准备缺少的共享运行时，再进入 MSI 的目录与快捷方式向导；独立 MSI 和 MSIX 继续提供
- 🌏 默认英语，继续提供简体中文、台湾繁体中文和日语
