# 🐍 PyDeck 0.7.0-fix

**English** · [简体中文](#简体中文)

## ✨ New tools

- 🧰 Prepare a private Python for CPython build tools, with pinned download verification and cancellation; C++ tools open the official installer page
- 🧹 Scan and clean build caches, temporary files and owned runtimes, with stale-data and registered-environment protection
- 🔗 Inspect which registered virtual environments use a runtime before removing it
- 📦 Manage packages inside virtual environments: search, install, upgrade, uninstall, prepare/upgrade pip, import/export requirements and inspect dependency warnings

## 🔧 Reliability and performance

- Independent task ownership: downloads and refreshes no longer disable unrelated controls
- Switch between concurrent progress displays and cancel the selected task independently
- Preserve settings drafts during unrelated background work; reject outdated catalog-source results
- Batch activity and progress notifications, retain bounded thread-safe log snapshots, and release obsolete control registrations
- Share version sorting rules and commit environment refresh atomically without overwriting concurrent edits
- 🌏 English remains the default; Simplified Chinese, Traditional Chinese (Taiwan) and Japanese remain available

## 📦 Downloads

Choose **MSI** or **MSIX** for Windows 11 x64. MSI uses full-package replacement upgrades, retaining installation location, shortcut choices and app settings. This is not a binary delta. MSIX keeps its existing self-signed identity; first-time users must explicitly trust the supplied public certificate. The private signing key is never distributed.

The release and download filenames use **0.7.0-fix**. Installer version **0.7.0** and tag **v0.7.0** stay numeric for Windows upgrade ordering and existing in-app update checks. Shared .NET / Windows App Runtime dependencies remain external. The standalone dependency helper provides official download links.

📖 Read `INSTALL.md` / `INSTALL.zh-CN.md` and compare downloads with `SHA256SUMS.txt`. GitHub provides source ZIP / tar.gz automatically; there are no duplicate uploaded source archives.

## 🧪 Validation scope

Development verification passed **108 core checks** and **26 GUI check groups**, including concurrent task state, a 3,000-notification UI burst, version ordering and environment-registry conflicts. Final signed-package and installer results are appended to the GitHub release after packaging. This change does not claim a new complete CPython build run, every historical source/toolchain combination, clean-machine deployment, or production MSIX certificate-trust installation validation.
