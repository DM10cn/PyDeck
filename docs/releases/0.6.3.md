# 🐍 PyDeck 0.6.3

**English** · [简体中文](#简体中文)

## 🛠️ Build your own Python

- Build x64 CPython from official source, with exact version selection, historical release discovery and local archive import
- Choose Standard, Performance (PGO), Debug, Minimal or Custom presets, with component, compiler/SDK and output choices
- Inspect commands, follow download and build stages, cancel a job, and reuse settings from build history
- Validated local runtimes appear in My Python and work with terminals and virtual environments without PIM
- Compact responsive build controls, reserved scrollbar space and retained scroll positions
- 🌏 English, Simplified Chinese, Traditional Chinese (Taiwan) and Japanese; English remains the default

📖 [Build guide](../BUILD_PYTHON.md) explains prerequisites, source verification and compatibility. An existing Python 3.10+ and compatible MSVC/Windows SDK are required. Selecting an old release does not guarantee support for its build scripts or compiler requirements. PyDeck orchestrates CPython; it does not distribute its own Python runtime.

## 📦 Downloads and upgrades

- MSI supports in-place major upgrades, retaining the installation folder and shortcut choices; it is a full replacement package, not a binary delta
- MSIX uses Windows-managed installation and the existing self-signed certificate; first-time installation requires trusting the supplied public certificate
- The standalone dependency helper opens official runtime downloads; .NET and Windows App Runtime remain external dependencies
- Source archives are supplied automatically by GitHub; no duplicate ZIP/tar.gz assets

📖 See the attached installation guides and verify downloads against `SHA256SUMS.txt`. Windows 11 x64 is required. MSI and MSIX are separate installation channels.

## ✅ Validation scope

Development validation passed 91 core checks and 23 GUI check groups. Actual CPython 3.14.7 Debug and 3.13.7 PGO builds passed runtime and virtual-environment checks. The PGO workload passed 9,364 tests; source paths with spaces exclude `test_tabnanny`, as documented in the build guide. Final installer validation is reported on the GitHub release after packaging. These checks do not certify every historical CPython, every compiler, compositor appearance or all accessibility settings.

### 🛠️ 构建自己的 Python

- 从官方源码构建 x64 CPython，支持指定完整版本、查询历史版本和导入本地源码包
- 标准、性能（PGO）、调试、精简和自定义预设，可选择组件、编译器 / SDK 与输出位置
- 查看执行命令、下载及构建阶段，取消任务，从历史记录复用配置
- 验证通过的运行时加入“我的 Python”，无需 PIM 即可用于终端和虚拟环境
- 构建选项紧凑排列，为滚动条预留空间，交互后保留滚动位置
- 🌏 支持英语、简体中文、台湾繁体中文和日语，默认英语

📖 [构建指南](../BUILD_PYTHON.md#简体中文)说明依赖、源码校验与兼容范围。需要已有 Python 3.10+ 和兼容的 MSVC / Windows SDK，选择旧版本不代表其构建脚本或工具链已经适配。PyDeck 负责编排，不发布自己的 Python 发行包

### 📦 下载与升级

- MSI 使用完整包覆盖升级，保留安装位置与快捷方式选择，不是二进制差分包
- MSIX 沿用现有自签证书，首次安装需要信任随包提供的公开证书
- 独立依赖工具提供官方下载入口，.NET 和 Windows App Runtime 仍为外部依赖
- 源码归档由 GitHub 自动生成，不重复上传 ZIP / tar.gz

📖 安装前查看附件中的安装指南并核对 `SHA256SUMS.txt`，仅支持 Windows 11 x64；MSI 与 MSIX 是独立安装渠道
