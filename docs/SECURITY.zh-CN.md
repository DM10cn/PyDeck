# 🔐 安全说明

[English](../SECURITY.md) · **简体中文** · [🏠 首页](../README.zh-CN.md)

## 📨 报告漏洞

请勿在公开 Issue 中提交凭据、个人信息、私有软件源或利用细节。如果仓库显示 **Security → Report a vulnerability**，请通过该入口私下报告；如果没有此入口，可先提交 Issue 请求私下联系方式，不要公开漏洞本身

私下报告时请提供受影响版本、影响范围和最小复现步骤。PyDeck 目前为开发预览版，暂不承诺安全支持周期或响应时限，修复面向当前开发分支

## 🧱 信任边界

- 🐍 **Python Install Manager 是受信任的可执行程序** — 发现与能力检查用于确认兼容性，不能证明文件真实性
- 📦 **离线包应来自可信来源** — SHA-256 只能按所选索引验证文件完整性，不能证明发布者身份
- 👤 **操作以当前用户身份执行** — PyDeck 不为 Python 操作请求提权，也无法防御已经控制该用户账号的攻击者
- 🔒 **操作锁协调 PyDeck 实例** — 独立运行的 PIM 命令和其他配置编辑器不参与此锁
- 🧰 **依赖恢复提供下载链接** — 软件包由用户手动安装，原生就绪检查不验证签名或发布者真实性

## 🛡️ 实现中的保护

| 边界 | 措施 |
| --- | --- |
| 进程调用 | PIM 命令不经过 shell，参数独立传入，限制 ID 字符和长度，管理器使用绝对本地路径，关闭标准输入 |
| 解释器变更 | 再次检查身份、托管关系和当前状态，串行执行变更与默认版本编辑，刷新并验证结果 |
| 离线输入 | 拒绝远程、绝对、路径穿越、备用数据流和重解析点路径，要求 SHA-256，检查 ZIP 条目和大小 |
| 离线执行 | 复制并校验到私有暂存目录，从验证后的副本安装，主源与回退源均为本地 |
| 输出 | 持续读取 stdout / stderr 并限制保留量，拒绝截断的列表响应，观察回调失败不阻塞管道读取 |
| 配置 | 限制读取大小，使用独立临时文件、落盘和原子替换，修改默认版本前备份，保留无关 JSON 字段 |
| 终端 | PowerShell 代码固定，所选解释器通过环境变量传入，不插入 shell 源码 |
| 依赖入口 | 固定的官方 HTTPS 下载地址，不运行安装程序或提权；包内启动器使用明确的相邻 GUI 路径，独立工具不启动 GUI |

取消只针对当前子进程树，等待进程退出并读完输出后才释放操作锁；若系统拒绝终止，锁会保留到进程退出。可取消的安装命令仅在自身进程环境中禁用 BITS 下载后端，避免后台服务继续下载，不影响其他 BITS 任务和持久环境设置

停止 Python 安装可能保留部分文件，PyDeck 不承诺自动回滚，也不会大范围删除 Python 目录。应用内的 Python 卸载没有中途取消入口；这里指 Python 操作，不是安装 PyDeck 自身的 Windows Installer 界面

配置检查用于降低误覆盖与路径重定向风险，不构成与其他工具共享的事务。离线源选择不会绕过 PIM 的管理员策略

原子替换配置时，对 Windows 的短暂共享 / 删除访问冲突最多重试 375 毫秒，每次重试都检查路径重定向和原文件指纹；发现外部修改即停止保存。持续占用会保留原文件并提示错误，不使用先删除再写入的回退方式

## 🗂️ 数据处理

PyDeck 不添加分析遥测，设置与有大小限制的崩溃诊断保存在本地。活动日志仅保留在内存中，限制为 2,000 行 / 1 MiB；单个进程输出流最多保留 8 Mi 字符，复制活动记录需要用户主动操作

日志与截图可能包含安装路径和管理器输出，分享前请检查。不要提交设置、日志、崩溃转储、包缓存、签名密钥或凭据，忽略规则不能替代提交前检查

## 🧪 验证边界

回归检查覆盖异常身份、非托管与陈旧版本拒绝、并发、配置保留、路径处理、超量输出、观察回调失败和离线归档校验。这些检查不等于独立安全审计，真实完整 Python 生命周期与任意第三方 PIM 配置的交互仍需验收。[功能状态记录](FEATURES.zh-CN.md)区分了这些待验收项目与已经完成的 PyDeck 安装器检查
